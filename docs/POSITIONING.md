## 4. Five service pillars

1. **Forward Deployed Engineering (FDE)** — discovery with customer teams, workflow analysis, rapid proof-of-value, integration, production deployment and handoff. On-site/embedded work is project-dependent, not a standing full-time-staff promise. Buyer language: "engineers work alongside your team."
2. **Custom Web & Mobile Software** — websites, apps, e-commerce, SaaS, portals, APIs, internal tools.
3. **AI Integration & Automation** — LLM apps, grounded knowledge/RAG, agents, document workflows, evaluations, human approval and controls.
4. **Enterprise Systems & Data** — legacy/tool integration, CRM/ERP interfaces, data pipelines, dashboards, workflow modernisation.
5. **Managed Engineering** — monitoring, maintenance, iterative improvement, scoped support agreements.

Each public service block should cover: problem → outputs → customer fit → engagement model.
