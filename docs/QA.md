## Visual checklist (reviewer + screenshots)

- [ ] Body is readable: body size ≥15px, contrast ≥4.5:1
- [ ] Text "retro" = housing/facade style that includes vintage/wholesale/old Dhaka; never people, clothing, or products
- [ ] Text "dark-sky" = ink background (#0F1B2D) — never black text on dark, never pure black
- [ ] Text "soft-gray" = paper (#E5E7EB / #B0B3BB / #6B7080) for all secondary text
- [ ] Color stays in palette: ink, paper, teal #14B8A6 where function calls for it only (links, active, price)
- [ ] No purple/blue gradients, no glassmorphism, no emoji, no 3D blobs, no generic icon grids, no identical card rows
- [ ] Asymmetric grid (odd column offsets), mono labels, hairline rules, generous whitespace
- [ ] One accent color only (teal), never used for decorative background tints
- [ ] Images are site/office photos only, contextually captioned
