# Brand — Hope Theory Labs

Source: Brand & Positioning System page (sections 4–6) and docs/SPEC.md. Use only these values.

## Colours

| Token | Hex | Use |
| --- | --- | --- |
| `ink` (Deep Ink / navy) | `#0F1B2D` | Main background, dark sections, headings, text on teal buttons |
| `teal` (Hope Teal) | `#14B8A6` | Buttons, highlights, particles. One sparing accent. **Never body text on light backgrounds.** |
| `tealDark` (Deep teal) | `#0F766E` | Links and teal text on light backgrounds |
| `paper` | `#F8FAFC` | Light sections, text on navy |
| `slate` | `#475569` | Secondary text on light backgrounds |

Contrast pairs that pass WCAG AA: ink on teal, paper on ink, tealDark on paper, slate on paper.

## Fonts (free Google Fonts, via `next/font/google`, subset, `display: swap`, only weights used)

| Role | Font | Weights |
| --- | --- | --- |
| Headings | Space Grotesk | 600, 700 (letter-spacing about -0.03em) |
| Body | Inter | 400, 600 |
| Labels / code | JetBrains Mono | 400 (small uppercase labels like `01 / HOW IT WORKS`) |
| Bangla | Hind Siliguri | 400, 600 |

## Logo

- Wordmark: lowercase "hope theory labs" in Space Grotesk with a teal dot.
- Favicon: "HT" monogram in a rounded navy square with a teal accent.

## Voice (site, pitches, agency LinkedIn)

- "We", humble, plain. Short sentences, plain words.
- Do: real prices (৳25,000 shown first, then founding ৳15,000 and why), a free concept first, "Reply whenever suits you".
- Don't: deadlines, countdowns, pressure, "AI magic", buzzwords, "my brother and I".
- Bangla or English, but never mixed mid-sentence. Bangla copy needs Fahad/Tamim review before going live.

## Fact guardrails

- No invented numbers, metrics, logos, clients, reviews or testimonials.
- No degree or education claims about anyone.
- Rollers Republic is always labelled **Concept**, never client work.
- Sthappo stays off the site until delivered and approved. No placeholder.
- AI services are shown only as **Early access**, with no prices.
